# OLX Parser

Красивий HTML/CSS/JS інтерфейс для пошуку товарів на OLX з Python-парсером.

## Запуск

```powershell
python server.py
```

Після запуску відкрий:

```text
http://127.0.0.1:8000
```

## Можливості

- пошук за назвою товару;
- мінімальна та максимальна ціна або `-`;
- сортування від дешевих до дорогих і навпаки;
- Python API `/api/search`;
- результати сортуються за реальною ціною, без пріоритету рекламних або топ-оголошень.
