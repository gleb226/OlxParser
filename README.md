# OLX Finder

Локальний вебінтерфейс для точного пошуку оголошень OLX з фільтрами за категорією, містом, продавцем і валютою.

## Запуск

```powershell
python run.py
```

Браузер відкриється автоматично. Якщо порт `8000` зайнятий, сервер сам вибере наступний вільний порт з `5000`, `8212`, `8080`, `3000`, `3001`, `3002` і покаже адресу в консолі.

## Можливості

- пошук за назвою товару;
- вибір категорії OLX;
- вибір міста зі списку або ручне введення свого міста;
- фільтр за мінімальною та максимальною ціною;
- вибір валюти фільтра: гривня, долар або євро;
- розпізнавання оригінальної валюти з OLX і перерахунок у гривні;
- фільтр за приватними або бізнес-продавцями;
- проксі для фото OLX, щоб картки частіше відкривали зображення.

Щоб зупинити сервер, натисни `Ctrl+C` у вікні консолі.
